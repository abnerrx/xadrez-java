Xadrez em Java:

Jogo de xadrez no console fiz pra praticar orientação a objetos da linguagem
(herança, polimorfismo e encapsulamento).

Como rodar:

Requer JDK instalado.

    javac *.java
    java Main

O que faz:

Tabuleiro 8x8 com todas as peças;
Movimento de cada peça (torre, cavalo, bispo, dama, rei e peão);
Captura e bloqueio de caminho;

O que falta:

Xeque e xeque-mate, roque, en passant, promoção do peão;
Interface gráfica;
